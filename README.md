# S.006 · Starryear-2x2

将一张原始摄影转译为四个彼此连续、逐层抽象的视觉状态：

`摄影证据 → 诗意提炼 → 结构抽象 → 抽象灵魂`

Starryear-2x2 以一张竖向 2:3 摄影为唯一内容与色彩来源，在精确的 2 × 2 网格中保留证据、提炼关系、抽象结构，并释放照片自身的视觉灵魂。
